# Back Acupoint Demo

一个面向 `理疗机器人` 方向的 Android 原生演示项目。

当前版本目标不是做临床级自动识别，而是先把下面这条演示链路做通：

- 手机后摄像头预览背部
- 叠加背部参考线和重点穴位
- 冻结当前画面
- 拖动锚点微调背部中线/肩点
- 穴位位置按规则同步更新

这适合用来做：

- 客户演示
- 方案评审
- 机器人视觉链路的前端原型
- 后续接入真正背部定位模型前的 UI/交互底座

## 当前能力

- `CameraX` 实时预览
- 背部中线、肩线引导框
- 15 个演示穴位点位
- 冻结画面
- 锚点拖拽校准

当前演示穴位包括：

- 大椎
- 左右肺俞
- 左右心俞
- 左右膈俞
- 左右肝俞
- 左右脾俞
- 左右胃俞
- 左右肾俞

## 技术栈

- `Kotlin`
- `Android View`
- `CameraX`
- 自定义 `Canvas Overlay`

## 运行方式

1. 确保本机已安装 Android SDK，且 `local.properties` 指向 SDK。
2. 连接 Android 手机并开启 USB 调试。
3. 在项目根目录执行：

```bash
./gradlew assembleDebug
```

如果要直接安装到设备：

```bash
./gradlew installDebug
```

## 演示建议

- 用后摄拍摄人体背部
- 让背部尽量居中、肩部完整入镜
- 点击“冻结画面”
- 拖动黄色锚点，让肩点和脊柱中线更贴近实际
- 观察穴位随锚点同步调整
