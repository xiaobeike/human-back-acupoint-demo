# Human Back Acupoint Demo

Language: **English** | [简体中文](README.zh-CN.md)

![Demo Screenshot](assets/screenshots/demo-screen.png)

An Android native demo for `rehab robot / wellness device capability presentation`.

This is not a clinical-grade acupoint localization system and not a production robot-control app. It demonstrates a practical PoC flow:

`back preview -> manual contour alignment -> acupoint mapping -> JSON export -> simulated device receiving`

## Positioning

Good for:

- customer demos
- solution presentations
- rehab robot UI prototyping
- first-stage PoC for back acupoint visualization

Not intended as:

- a medical product
- a clinical localization tool
- a final robot control system

## Features

- rear-camera live preview with `CameraX`
- fixed back contour template
- three body templates: `Slim / Standard / Wide`
- 3-step alignment flow: shoulders, spine centerline, waist width
- six draggable anchors
- acupoint overlay after lock
- selected acupoint info card
- full payload JSON page
- single-acupoint JSON page
- simulated device receiver page
- current screen export

## Acupoints

The demo currently includes `30` back acupoints across the Governor Vessel and bilateral back-shu lines.

- Governor Vessel: `Taodao` `Dazhui` `Shendao` `Mingmen`
- Bilateral back-shu set:
  `Dazhu` `Fengmen` `Feishu` `Jueyinshu` `Xinshu` `Geshu` `Ganshu` `Danshu` `Pishu` `Weishu` `Sanjiaoshu` `Shenshu` `Dachangshu`

These points are not AI-detected in the current version. They are generated by rule-based mapping using `vertical_t`, `lateral_t`, the spine axis, shoulder width, and waist width.

## Demo Flow

1. Open the app and preview the back with the rear camera.
2. Choose the closest body template.
3. Tap `开始校准`.
4. Align shoulders, spine centerline, and waist width.
5. Lock the alignment.
6. Inspect the acupoint overlay.
7. Select an acupoint.
8. Inspect the single or full JSON payload.
9. Send it to the simulated device.

## JSON Output

Current output types:

- `full acupoint payload`
- `single-acupoint payload`

Fields include:

- template name
- capture time
- canvas size
- shoulder width, waist width, spine axis length
- anchor coordinates
- acupoint pixel coordinates
- normalized coordinates
- `vertical_t / lateral_t`

## Getting Started

Prerequisites:

- Android Studio / Android SDK
- `local.properties` points to your local SDK
- an Android device with developer mode and USB or Wi-Fi debugging enabled

Build:

```bash
./gradlew assembleDebug
```

Install:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Launch:

```bash
adb shell am start -n com.humanacupoints.demo/.MainActivity
```
