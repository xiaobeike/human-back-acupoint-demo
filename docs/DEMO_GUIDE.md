# Demo Guide

## 演示建议

推荐按下面顺序演示：

1. 先说明这不是“自动医疗定穴”，而是“背部穴位数字化演示能力”
2. 展示系统先做人背轮廓定位，再根据锚点推算其余穴位
3. 锁定后选中一个穴位
4. 展示该穴位的单点 JSON
5. 点击发送到模拟设备
6. 展示设备已接收结果

这样更容易让观众理解：

- 输入是什么
- 中间做了什么计算
- 输出给谁使用

## 已知边界

当前版本是展示版交互原型，不是最终机器人控制系统。

当前不包含：

- 自动人体分割
- 自动骨性标志识别
- 深度信息
- 相机坐标到机器人坐标转换
- 安全力控
- 真实设备通信协议

## 后续路线

如果继续往产品方向推进，优先级最高的方向通常是：

1. 自动背部锚点检测
2. 多穴位治疗序列
3. 真实设备接口
4. 相机坐标到机器人坐标转换
5. 深度 / 三维定位
6. 安全区域与力控策略
